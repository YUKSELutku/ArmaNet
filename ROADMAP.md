# ArmaNet Roadmap

## V0.1 - MVP

* Physical-device validation across Android/OEM versions
* DNS relay reliability fixes discovered during device testing
* Accessibility and empty/error-state polish

## V0.2 - Better Filtering

* Signed remote ruleset manifest and atomic download/update
* Rollback storage and update health checks
* Multiple curated lists and import/export for user custom rules
* Domain search and improved categorization

## V0.3 - Firewall

* Full TCP/UDP forwarding engine, including TCP DNS
* Per-application internet rules
* Wi-Fi and mobile-data policies
* Better UID attribution across Android versions

## V0.4 - Privacy Dashboard

* Daily and weekly aggregates
* Most active apps and contacted domains
* Tracker exposure summaries and charts
* Local export/import

## Future

* DNS-over-HTTPS and DNS-over-TLS upstreams
* Custom DNS providers
* Tablet layouts and accessibility polish
* Optional encrypted local backups
